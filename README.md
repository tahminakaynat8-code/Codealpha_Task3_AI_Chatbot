# CodeAlpha Task 3 - AI Chatbot

A Java-based AI Chatbot developed as part of the CodeAlpha Java Programming Internship.

## Features

- Interactive GUI using Java Swing
- Rule-based NLP and keyword matching
- Frequently asked questions and responses
- Time-stamped chat messages
- Clear chat option
- Exit confirmation
- Enter key support

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- Natural Language Processing (NLP)

## How to Run

1. Compile the program:
   javac AIChatbot.java

2. Run the chatbot:
   java AIChatbot
